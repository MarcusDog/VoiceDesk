# VoiceDesk 个人版 24 项产品蓝图 v1.1

更新日期：2026-09-27
产品定位：Windows 11 单用户、本地优先的语音知识工作区。无需账号，不建设团队空间；音频与语音识别留在本机，AI 文档由 MiniMax-M3 主引擎或本地 Qwen 备用引擎生成。

## 产品边界

- 单用户、单设备、SQLite 本地数据；不包含团队成员、权限、共享审批、在线协作和云同步。
- faster-whisper 负责真实本地语音转文字。首次模型获取优先使用镜像，失败后回退官方源。
- MiniMax-M3 是 AI 文档主引擎。仅在用户主动点击生成时发送转写文字，不上传音频。
- MiniMax 密钥进入 Windows 凭据管理器；前端只能读取“已配置/未配置”，不能读取原文。
- Qwen3-4B GGUF 是断网备用。模型需通过固定大小与 SHA-256 校验。

## 主流程

1. 用户导入音视频或用麦克风录音。
2. faster-whisper 在本机解码和转写，片段增量写入 SQLite。
3. 用户校对、搜索、替换并可直接导出字幕或文本。
4. 用户主动生成文档；已配置 MiniMax 时发送转写文字到固定 API，否则用本地 Qwen。
5. 引擎生成结构化结果并做第二遍事实审校，每条结论保留来源序号。
6. 文档保存到本机，可回到原转写核对并导出。

## 发布门槛

- 新密钥实网连接和一次真实文档生成通过。
- 安装版录音、本地 ASR、AI 文档、导出闭环通过。
- 无控制台窗口、无密钥落盘、日志不含 Authorization 或正文。
- 完成断网、权限拒绝、磁盘不足、模型损坏的恢复验证。
