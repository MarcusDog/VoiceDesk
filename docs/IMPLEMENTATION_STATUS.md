## 已验证的用户路径

1. 首次启动：阅读隐私边界 → 检查硬件/模型 → 进入工作区或前往模型设置。
2. 文件转写：选择/拖入媒体 → 建项目和任务 → GPU 推理/CPU 回退 → 增量保存 → 编辑与导出。
3. 录音转写：授权麦克风 → 分块写入本地 → 暂停/继续 → 保存并自动转写。
4. AI 纪要：选择已转写项目 → MiniMax-M3（或本地 Qwen 备用）→ 分段整理 → 结构化 JSON → 事实审校 → 来源落库。
5. 内容整理：审核低置信度片段 → 接受/忽略 → 自动章节跳转 → 笔记/草稿自动保存。
6. 异常恢复：运行中退出后任务变为 paused；ASR 可安全重跑；LLM/ASR 可取消进程；误删项目可从回收站恢复。

## 发布前仍需完成的 P0

- 建立并跑完 10/30/60 分钟中文、中英混合、噪音和多人会议评测集。
- 自动说话人分离尚未接入；当前已支持人工命名与同说话人批量改名。
- 单媒体真实播放与时间戳 seek 已完成；多文件项目仍需加入连续播放列表。
- 回收站与恢复已完成；仍需补充更细粒度的编辑版本历史和撤销。
- 浏览器布局已通过 1920×1080、1400×900、1000×760、700×760、680×520 以及 125% 放大模式的中文断行、按钮宽度、滚动与溢出检查；仍需完成原生 WebView2 键盘、屏幕阅读器和高对比度人工验收。
- 完成安装、升级、卸载、磁盘不足、断网、模型损坏、麦克风拒绝权限的安装包级测试。
