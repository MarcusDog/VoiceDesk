## 本轮发现并修复

1. 模型下载补齐固定大小与 SHA-256 校验、`.part` 断点续传、官方源失败/超时后镜像回退、异常超长/损坏文件处理；官方源 10 分钟未完成即保留断点切换镜像，网络失败保留断点供下次继续。
2. 增加全局重任务互斥，ASR 与 LLM 不会同时抢占 GPU/内存；任务启动失败或结束后会可靠释放占用。
3. 修复“取消发生在子进程登记前”的竞态：worker 会再次读取任务状态并立即终止已取消任务。
4. 补齐 Tauri `dialog:allow-save` 权限，保证转写导出可打开原生保存对话框。
5. 删除运行时 Google Fonts 依赖并收紧 CSP；除用户主动下载模型外，应用正文不访问外部服务。
6. 首次启动加入欢迎、隐私与硬件/模型三步引导；未安装 LLM 时可直接进入设置。
7. 删除伪 AI 对话和误导性交互：未完成的筛选、播放器、分享、草稿和设置操作现在明确禁用并说明原因。
8. 修复浏览器 favicon 404，补充自动化 UI 烟测脚本 `scripts/cdp-qa.mjs`。

## 用户场景覆盖

- 首次使用：无需账号；先说明本地数据边界，再检查硬件与模型。
- 官方下载慢或中断：自动切换镜像；重新点击后从 `.part` 继续；成功前不会把文件当作可用模型。
- 无 NVIDIA GPU：ASR 自动回退 CPU int8；LLM 可使用 llama.cpp CPU，但速度会明显降低。
- GPU/内存紧张：只允许一个 ASR 或 LLM 重任务；第二个任务得到明确错误。
- 麦克风拒绝、空录音、媒体不存在、模型损坏、引擎退出：返回用户可读错误，不把失败任务伪装为完成。
- 应用异常退出：运行中任务下次启动恢复为 paused；ASR 可安全重跑。
- 隐私与诊断：诊断包不含音频、转写正文和文件内容；当前版本无遥测。

## 尚未完成，不能标记为完整产品

### 发布阻断项

- 10/30/60 分钟中文、中英混合、噪声、多人会议批量评测尚未建立。
- 说话人分离和说话人重命名尚未接入。
- 工作区仍缺真实媒体播放、波形 seek 与时间戳跳转。
- 原生 WebView2 的完整键盘、高对比度、屏幕阅读器人工验收尚未完成。
- 安装/升级/卸载、断网、磁盘不足、麦克风拒绝、模型损坏等安装包级矩阵尚未跑完。
- 当前 `main` 工作区仍是全部未跟踪的初始工程，没有可用于变更追溯的 Git 基线、CI 或发布标签；本轮没有擅自替产品负责人创建提交历史。
- 安装器尚未代码签名，Windows SmartScreen 可能显示“未知发布者”。

### 后续版本功能

Review Mode、Auto Chapters、Draft Editor、项目回收站/撤销、跨项目全文索引、完整本地问答、提醒、系统音频录制、实时会议转写、云同步和团队协作仍未实现。界面已避免把这些能力展示为可用。

## 发布判定

v0.3.0 可作为本地 Alpha/技术预览交付，用于“导入或录音 → 转写 → 编辑/搜索 → AI 纪要 → 来源追溯 → 导出”的单机闭环验证。它不应被描述为 24 项蓝图全部完成，也不建议在完成上述发布阻断项前称为正式版。
