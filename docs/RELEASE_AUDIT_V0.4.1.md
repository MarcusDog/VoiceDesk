# VoiceDesk v0.4.1 可用性修复与发布审计

更新日期：2026-09-28

## 本次完成

- 为转写、章节、笔记、草稿和页面主体补齐独立纵向滚动区域，避免内容被固定高度容器裁切。
- 新增 100% / 110% / 125% 界面与字体缩放设置，默认 110%，即时生效并保存到本机。
- 项目标题与每条转写片段的三点按钮改为真实菜单；无功能的三点入口从界面隐藏。
- 最小桌面窗口由 900×640 调整为 680×520；窄窗口会折行、隐藏辅助栏并允许整页滚动。
- ASR 加载前校验本地模型快照。缓存完整时直接传入本地路径并启用离线模式，不再向 Hugging Face 发起解析请求。
- 模型状态明确区分“正在加载本机识别模型”和“正在下载识别模型（仅首次使用）”。
- ASR 错误文案区分语音识别与 AI 文档引擎，不再统一显示误导性的 AI 错误。

## 根因

1. App Shell 使用固定视口高度并隐藏溢出，而工作区列表没有 `min-height: 0` 与独立 `overflow-y: auto`。
2. 原生窗口最小尺寸和三栏固定宽度过大，窄窗口没有完整降级路径。
3. 多个省略号按钮是禁用占位符，转写片段操作也没有菜单实现。
4. faster-whisper 接收模型名时仍会走远端快照解析；即使权重已经在本机，也会显示下载/加载混合文案并受网络影响。

## 验证结果

- 前端生产构建：通过，1904 个模块。
- Rust Core：11 个单元测试全部通过。
- Python ASR / LLM：9 个测试全部通过。
- Rust Clippy：`-D warnings` 通过。
- UI：720×560 和 680×520 断点无内容栏横向丢失；转写列表与页面均检测到可用纵向滚动；项目与片段菜单可展开；125% 字体模式即时生效。
- 打包侧车真实转写：使用现有 `small` 模型缓存处理本机 WebM，返回 `cached: true`、CUDA `float16`、1 个真实片段并正常完成；未触发重新下载。
- 发布模式使用 Windows GUI 子系统，启动应用不会显示后台命令行窗口。
