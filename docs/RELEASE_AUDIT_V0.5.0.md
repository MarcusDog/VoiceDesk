# VoiceDesk v0.5.0 中文界面与 AI 文档升级审计

更新日期：2026-09-28

## 界面调整

- AI 文档页改为“页面标题、生成命令栏、文档列表、文档正文”四层结构。
- 页面标题不再承载模型选择、实现原理或隐私说明等介绍性长文案。
- 生成、取消、复制、重新生成和打开转写按钮设置稳定宽度并禁止单字竖排。
- 文档标题、项目名和元数据使用独立可用宽度，长标题按中文语义换行。
- 1500px 以下自动隐藏右侧 AI 工具栏；1180px 以下切换为图标导航；700px 以下命令栏改为单列。
- 修复 125% 放大时视口滚动条引起的 15px 横向溢出。
- 折叠导航补齐中文 `aria-label`。

## AI 文档能力

- 会议纪要：摘要、明确结论、关键讨论、待办、风险。
- 执行摘要：管理者摘要、核心结论、关键事实、下一步、风险。
- 行动清单：目标与决策、工作事项、负责人、期限、阻塞项。
- 访谈洞察：核心洞察、主题与观点、后续研究、待验证问题。
- 四种模板在前端、Rust Core 和 Python AI 侧车中使用同一白名单。
- 提示词版本升级为 `structured-docs-v2`；每种模板使用不同摘要要求、区块语义和标题后缀。
- 所有模板继续执行来源引用校验和第二遍事实审校。
- 文档正文支持复制 Markdown、按原模板重新生成和返回来源转写。

## 验证

- 前端生产构建通过：1904 个模块。
- Python ASR / LLM：11 项测试通过，其中包含模板白名单与行动清单提示词回归。
- Rust Core：12 项测试通过，包含文档模板白名单测试。
- Rust Clippy：`-D warnings` 通过。
- 浏览器运行无 console warning/error。
- 1920、1400、1000、700 像素与 125% 字体模式无横向溢出，生成按钮保持单行。
